import { Card, CardGrid } from '@astrojs/starlight/components';

<CardGrid>
  <Card title="Compose Multiplatform">
    Ditto is a UI toolkit for Compose, so it runs wherever you already write Compose: Android, iOS,
    desktop on the JVM, and the browser through Wasm. Components live in `commonMain` and there is
    no per-platform source set to keep in sync — this page's live demos are the same code running
    in a browser.
  </Card>
  <Card title="Platform adaptive">
    Every platform has its own idea of what a control looks like, and users notice when an app gets
    it wrong. Write the screen once and Ditto renders it as each platform expects: Material-ish on
    Android, flat and tinted on iOS, compact and dense on the desktop. The idiom is a runtime
    value, so you can pin it, preview it, or let the platform choose.
  </Card>
  <Card title="Components">
    Thirty-three components — buttons, fields, sheets, menus, tabs, trees, split panes, scrollbars —
    across sixty-odd composables. Restyle any of them globally with a transform that applies on top
    of the idiom default, so your brand travels without flattening the platform underneath it.
  </Card>
  <Card title="Getting started">
    Add one dependency, wrap your app in `DittoTheme`, pick an accent colour. **[Start
    here](/ditto/getting-started/)** for the artifacts, the theme, and a worked example you can
    switch between platforms as you read it.
  </Card>
</CardGrid>
