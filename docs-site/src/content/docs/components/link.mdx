Ditto has one link mechanism with two shapes. Most links live **inside a sentence**, so that is the
case to reach for first; `Link` is the standalone form for a "Learn more" on its own line. Both are
`LinkAnnotation` underneath, so both carry real link semantics rather than announcing themselves as
buttons.

## Inside a sentence

`LinkDefaults.textLinkStyles()` gives you the idiom's link styling as `TextLinkStyles`, ready for
`withLink`:

```kotlin
val linkStyles = LinkDefaults.textLinkStyles()

Text(
  buildAnnotatedString {
    append("By continuing you agree to the ")
    withLink(LinkAnnotation.Url("https://example.com/terms", linkStyles)) { append("Terms") }
    append(".")
  },
)
```

`LinkAnnotation.Url` hands the destination to the platform's URI handler. Use
`LinkAnnotation.Clickable` when navigating means something in-app:

```kotlin
withLink(LinkAnnotation.Clickable("terms", styles = linkStyles) { navigateTo(Terms) }) {
  append("Terms")
}
```

<Aside type="tip" title="Hoist the styles out of the builder">
  `textLinkStyles()` is a composable read, and `buildAnnotatedString` takes an ordinary lambda. Read
  it first, then use it inside — and key your `remember` on it so the string rebuilds when the
  idiom or colour mode changes.
</Aside>

## Standing on its own

```kotlin
Link("Learn more", onClick = { navigate() })

// Leaving the app: adds an arrow glyph described as "opens externally"
Link("Read the licence", onClick = { openBrowser() }, external = true)
```

`Link` is a single string, not a layout — it cannot hold a sentence with a link in the middle. That
is what the inline form above is for.

## Specification

| | Android | Apple | Desktop |
|---|---|---|---|
| Colour | `accent` | `accent` | `accent` |
| Underline | always | never | on hover |

That rule is `LinkStyle.underline`, and it is the reason to use these helpers rather than colouring
a `SpanStyle` yourself — Material underlines links in body text, iOS relies on colour, and desktop
UIs reveal the underline on hover.

**Focus underlines in every idiom**, including Apple, which otherwise never does. A focus indicator
that is only a colour change is not an indicator.

## Accessibility

- The link is a real `LinkAnnotation`, so it is focusable, activatable and announced as a link.
  Compose has no `Role.Link`, so a hand-rolled clickable text can only claim to be a button — which
  is why this component was rebuilt on the annotation.
- A disabled `Link` drops the annotation entirely rather than dimming a live one, so it takes no
  tab stop and offers nothing to activate.
- `external` adds an arrow described as "opens externally". The glyph is sized from the surrounding
  text, so it tracks the font scale.

## API

```kotlin
@Composable
fun Link(
  text: String,
  onClick: () -> Unit,
  modifier: Modifier = Modifier,
  enabled: Boolean = true,
  external: Boolean = false,
  style: LinkStyle? = null,
)

object LinkDefaults {
  @Composable fun style(idiom: Idiom = DittoTheme.idiom): LinkStyle
  @Composable fun resolve(style: LinkStyle? = null): LinkStyle
  @Composable fun textLinkStyles(style: LinkStyle? = null): TextLinkStyles
}

class LinkStyle(
  val textStyle: TextStyle?,      // null inherits LocalTextStyle
  val color: Color,
  val disabledColor: Color,
  val underline: LinkUnderline,   // Always, Never, OnHover
)

val LocalLinkStyle: ProvidableCompositionLocal<LinkStyle?>
```
