Confirms something happened, and optionally offers to undo it. It does not interrupt: if the user
misses it, nothing is lost. When the message must be acknowledged, use a
[dialog](/ditto/components/dialog/); when it must stay visible, a
[banner](/ditto/components/banner/).

## Usage

```kotlin
val snackbars = remember { SnackbarHostState() }
val scope = rememberCoroutineScope()

Scaffold(snackbarHost = { SnackbarHost(snackbars) }) { padding ->
  Button(
    onClick = {
      scope.launch {
        val result = snackbars.showSnackbar("Saved to library", actionLabel = "Undo")
        if (result == SnackbarResult.ActionPerformed) undo()
      }
    },
  ) { Text("Save") }
}
```

`showSnackbar` suspends until the snackbar is dismissed or its action is tapped, and returns which
happened. A mutex means a second call waits rather than stealing the screen — messages queue
instead of colliding.

<Aside type="tip" title="One action, and make it Undo">
  A snackbar disappears; anything behind a second button is effectively hidden. The action that
  earns its place is the one that reverses what just happened.
</Aside>

## Durations

| Duration | Length |
|---|---|
| `Short` | 4 seconds |
| `Long` | 10 seconds |
| `Indefinite` | until dismissed |

A snackbar with an action defaults to `Long`, since four seconds is not long enough to notice an
offer and act on it. Use `Indefinite` only with an action or a dismiss affordance, or it never leaves.

## Specification

| | Android | Apple | Desktop |
|---|---|---|---|
| Look | inverse bar, 4dp radius | floating capsule on `surfaceRaised` | bordered toast, 12dp radius |
| Position | bottom centre | bottom centre | bottom end |

## Accessibility

- A polite live region, so the message is announced without interrupting.
- The action is a real button in the focus order for as long as the snackbar is up.
- Anything conveyed only by a snackbar is lost to a user who was looking elsewhere — never make it
  the only record of an error.

## API

```kotlin
@Composable fun SnackbarHost(state: SnackbarHostState, modifier: Modifier = Modifier, style: SnackbarStyle? = null)
@Composable fun Snackbar(data: SnackbarData, modifier: Modifier = Modifier, style: SnackbarStyle? = null)

suspend fun SnackbarHostState.showSnackbar(
  message: String,
  actionLabel: String? = null,
  duration: SnackbarDuration = if (actionLabel == null) SnackbarDuration.Short else SnackbarDuration.Long,
): SnackbarResult
```
